Retail Sales & Profitability Analysis

Project Overview
This project analyzes retail sales and profitability data using Microsoft Excel. The dashboard helps explore sales performance across product categories, regions, and time.

Tools Used
- Microsoft Excel
- Excel Tables
- PivotTables and PivotCharts
- Slicers
- Data Cleaning and Date Formatting

 Key Performance Indicators (KPIs)
 Total Sales: 14,956,982
 Total Profit: 3,747,121.20
 Profit Margin: 25.05%

 Dashboard Features
- Category-wise Sales and Profit Analysis
- Region-wise Sales and Profit Analysis
- Monthly Sales Trend
- Interactive Category and Region slicers
- KPI summary for quick performance review

 Key Findings
- Bakery recorded the highest sales among categories.
- Snacks recorded the highest profit among categories.
- The West region recorded the highest sales and profit among regions.

Project Objective
The objective is to practice Excel data analysis, summarize business performance, and present insights through an interactive dashboard.

 Files
- `Retail_Sales_Profitability_Analysis.xlsx` — Excel workbook containing the analysis and dashboard.

 Note
This is a learning project created to develop practical data analysis skills. Figures and findings are based on the workbook's current analysis.
